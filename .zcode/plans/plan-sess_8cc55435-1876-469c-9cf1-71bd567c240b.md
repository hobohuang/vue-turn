# 封面/封底声明式 prop + 专用封面纸张（正反面同纸）方案

## 核心洞察（决定了改动范围很小）

现有索引空间里，一张纸的配对规律是 **sheet k = (偶索引, 奇索引)**：封面纸张今天就是 (0,1)，封底纸张今天就是 (last-1, last)（见 `flipSpec.ts:42-117` 的四个特例）。问题在于索引 1 和 last-1 目前被**普通内容页借用**（第一个内容页粘在封面背面、最后一个内容右页粘在封底正面），导致 `sheetOptions`（`VueTurn.vue:532-536`）按"任一面是 cover"给整张纸套封面卷曲参数——正是你说的纸张类型冲突。

因此新模型**不动索引结构和奇偶规则**，只把这两页变成专用页：

```
index 0    = 封面（cover item 正面）
index 1    = 封面底（#back 插槽内容，未定义则空白）      ← 专用化
index 2+   = 内页内容（跨页仍须从奇数索引开始）
index last-1 = 封底里（#back 插槽内容，未定义则空白）    ← 专用化
index last = 封底（backCover item）
```

`flipSpec` 四个封面/封底特例的索引、delta、`pageStack`、`useBookState.clampAndAlign` **全部不需要改**——索引 0/1/last-1/last 的语义本来就按这个配对模型工作。

## API 设计

```html
<VueTurn>
  <TurnItem cover>
    封面
    <template #back>封面底（可选，不写则空白）</template>
  </TurnItem>
  <TurnItem>第 1 页</TurnItem>
  <TurnItem spread>跨页</TurnItem>
  <TurnItem back-cover>
    封底
    <template #back>封底里（可选）</template>
  </TurnItem>
</VueTurn>
```

- 未声明 `cover` / `backCover` 时沿用位置约定兜底：首 item = 封面、末 item = 封底，背面空白（单一映射路径）。
- **纸张类型不新增 prop**：封面与封底继续共用现有 `coverPreset`，封面底/封底里与封面/封底同纸（`cover: true`）→ 整张纸按封面观感（curl/nPolygons/封面灯光层）渲染，`sheetOptions` 现有逻辑直接成立，无需改动。
- 行为变化说明：原粘在封面背面的首个内容页移到索引 2（更符合真实书籍：翻开封面见空白衬页+右页正文）。

## 逐文件改动

### 1. `src/lib/pageMapping.ts`（核心重写）
- `PageItemLike` 扩展：`{ spread: boolean; face?: 'coverFront' | 'coverBack' | 'backCoverFront' | 'backCoverBack' }`（face 由 VueTurn 标注；纯函数不变式保留）。
- `buildPageSources` 新算法：
  1. 取 coverFront 面（未标注则提升首个内容面，其余 cover 标注告警后忽略）；coverBack 面缺失 → 空白页（`blank: true, cover: true`）。
  2. `sources[0] = coverFront`，`sources[1] = coverBack | 空白`。
  3. 内容面从 `pageIndex = 2` 起填充；跨页落偶数索引时插空白（规则同今天，仅起点从 1 → 2）。
  4. 追加封底里（backCoverBack 面 | 空白）、封底（backCoverFront 面，未标注则提升最后一个内容面）。backCover 的 spread 标注忽略（与今天封面一致，告警）。
  5. **补页逻辑调整**：奇数补偶从"全局补在末项前/书末"简化为"内页区段计数为奇 → 在封底里之前补一张空白"。原因：封底固定占 last，不再需要今天"补在末项之前让封底落在最后索引"的技巧（`pageMapping.ts:59-70` 整段替换）；补在内页区段末尾永远不会破坏跨页奇数对齐。
  6. 退化情形：全书仅一个 item → 该面同时作封面与封底（sources = [封面, 空白, 空白, 封底]，itemIndex 同源）。
- `PageSource` 不加新字段，`coverPageIndices` 不变（自然收集 0、1、last-1、last 四页）。
- 更新文件头注释。

### 2. `src/components/TurnItem.vue`
- 新增布尔 props：`cover`、`backCover`（透传渲染逻辑不变，`#back` 插槽天然存在）。

### 3. `src/components/VueTurn.vue`
- `collectPages()`（:293-317）：读取 `cover`/`backCover` prop → `role`；从组件 vnode 的 children 中提取 `#back` 插槽 vnode。
- 新增 `pageFaces` computed：把 item 展开为"面"列表（主面 + 可选背面相邻排列），`pageSources = buildPageSources(faces)`；`itemIndex` 语义变为面索引（下游 mergeSpread/usePageTextures 按 index 用，无需改名，注释更新）。
- 离屏 DOM（:782-796）：`v-for` 改为遍历 faces（背面面为单页宽 div）。
- `sheetOptions`（:532-536）**不改**：封面/封底/封面底/封底里均为 `cover: true`，任一面命中即整纸走封面档，共用 `coverPreset`。

### 4. 下游无需改动的确认项
`flipSpec`（特例索引/delta 不变）、`spreadLayout`/`mergeSpreadPlacements`（内容面配对按 itemIndex 同源，不受影响）、`pageStack.ts`（coverFlat/backFlat 判断照旧成立）、`useBookState.clampAndAlign`、`usePageTextures`（blank 跳过光栅化、mutationsToPages 按面索引映射）、`useFlipInteraction.hitRegion`（blank → 无命中区域，但纸张网格仍在、可拖拽翻页）、`TurnScene`（createSheet 对 null 纹理已有纯色材质兜底 → 空白封面底显示 pageBackground 纸色）。
